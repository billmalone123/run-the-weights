# Credits

## Free Exercise DB

A small set of exercises in Run the Weights (marked `src:"fedb"` in the code) started from Free Exercise DB by yuhonas:
https://github.com/yuhonas/free-exercise-db

Free Exercise DB is released under the Unlicense, which places it in the public domain. Its exercise data was collected from the earlier exercises.json project by wrkout:
https://github.com/wrkout/exercises.json

Only names, muscle groups, equipment and level were used, and every name and cue was rewritten for this app. No images from the dataset are included.
